Get started with Orqentis

  1. Open Microsoft Fabric in an approved tenant with Orqentis enabled.
  2. Create an Orqentis Data Contract item in a workspace backed by Fabric capacity.
  3. Select a Lakehouse and Delta table.
  4. Review or edit the generated ODCS v3.1.0 YAML.
  5. Save, activate, and run enforcement.
  6. Open the Contract Report item to review run history and breach details.

For tenant onboarding, offboarding, and support intake details, see the customer onboarding documentation in the product repository.
