Get started with Orqentis

  1. Open Microsoft Fabric in an approved tenant with Orqentis enabled.
  2. Create an Orqentis Data Contract item in a workspace backed by Fabric capacity.
  3. Select a Fabric target: Lakehouse, Warehouse, Eventhouse/KQL database, Semantic Model, or Fabric SQL database.
  4. For Lakehouse targets, select a Delta table. For other Fabric targets, enter the governed object path or name.
  5. Review or edit the ODCS v3.1.0 YAML. Enterprise tenants can use AI suggestion to draft the first version.
  6. Save, activate, and run enforcement.
  7. Open the Contract Report item to review run history and breach details.

Where AI helps

Orqentis AI is designed to shorten contract creation, explain breach impact, recommend remediation, and answer natural-language governance questions across contract metadata.

For tenant onboarding, offboarding, and support intake details, see the customer onboarding documentation in the product repository.
