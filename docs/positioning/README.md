# Orqentis Positioning Docs — Index

> **One-line summary:** This directory contains the complete MVP positioning and go-to-market artifact set for Orqentis, repositioned as AI Readiness & Data Security for AI Agents on Microsoft Fabric.

**Locked tagline:** *Contract-bound data for every AI agent on Microsoft Fabric.*

**Locked feature names** (used consistently across all documents):
1. **Agent-Ready Contract Co-Author** — AI-powered ODCS v3.1.0 authoring from Delta table profile
2. **AI Blast-Radius Scorer** — downstream AI consumer severity ranking on contract breach
3. **Pre-Copilot Contract Gate** — real-time contract status check before Copilot/agent grounding
4. **AI Act Evidence Pack** — one-click regulatory compliance bundle (EU AI Act, NIST AI RMF, ISO 42001)
5. **AI Governance Assistant** — natural-language governance queries across the contract estate

## How to Use These Documents

**New customer demo prep:** Read `mvp-demo-script.md`. Use the discovery questions to qualify the customer before booking a full SE demo.

**Competitive displacement deal:** Read `competitive-matrix.md`. Use the "How We Win" section for the talk track; use the "How We Lose" section to prepare objection handling.

**Investor or analyst meeting:** Start with `investor-onepager.md` (print or share as PDF). Use `ai-readiness.md` as the technical grounding document for follow-up questions.

**Content / PR / analyst relations:** Use `messaging-pillars.md` as the message architecture. Every content piece should reinforce one of the three pillars and use the locked feature names.

**Sprint or product planning:** Feature names in this directory are the canonical names. Use them in FR-IDs, sprint runbooks, and UI copy. The spec section cross-references are in each document.
