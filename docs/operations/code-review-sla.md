# Code review SLA

## Targets

- First human review within 24 business hours.
- Merge or explicit deferral decision within 72 business hours for ready PRs.
- Sev 1 fixes receive immediate review from the on-call secondary or platform lead.

## Expectations

Authors keep PRs small, include test evidence, and respond to review comments within one business day. Reviewers focus on correctness, security, operability, and adherence to `.github/copilot-instructions.md`.

## Escalation

If a PR misses the first-review target, tag the code owner and the on-call secondary. If it blocks a release or incident fix, escalate to the platform lead.
