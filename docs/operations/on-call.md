# On-call

## Rotation pattern

Use a weekly primary/secondary rotation. The primary owns pages and incident coordination; the secondary backs up the primary and reviews Sev 1 changes.

## Paging escalation

1. Page primary on-call for Sev 1 symptoms.
2. If unacknowledged after 15 minutes, page secondary.
3. If unacknowledged after another 15 minutes, escalate to the platform lead.
4. For customer-visible Sev 1 incidents, start customer communications within one business hour.

## Handoff

Each handoff records open incidents, risky deployments, current feature flags, alert noise, and follow-up actions.
